# Tauri Icons

This directory will contain the application icons.

For now, you can use placeholder icons or generate them using:
```bash
npm run tauri icon path/to/your/icon.png
```

Required icons:
- icon.icns (macOS)
- icon.ico (Windows)
- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.png (for system tray)
